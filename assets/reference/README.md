# Property reference photographs

The 14 images here are the user's supplied originals, committed at the user's
request for repeatable camera alignment. No image pixels were generated or
retouched. `montanaHouseAndClearingDrone.png` was originally uploaded as
`image(2).png`; the other filenames are retained.

The manifest `../photo-references.json` records original filenames, dimensions,
labels and starting viewpoints. See `../../docs/photo-matching.md` for the
in-scene photo picker and alignment export workflow. Different trips show
different vegetation conditions; the green-season photos guide scene colors.
