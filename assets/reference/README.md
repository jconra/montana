# Property reference photographs

The 28 images here are the user's supplied originals, committed at the user's
request for repeatable camera alignment. No image pixels were generated or
retouched. `montanaHouseAndClearingDrone.png` was originally uploaded as
`image(2).png`; the other filenames are retained, including `montanaDJ10.jpg` and the cabin close-up `montanaCabinDeckDrone.png`
(the tenth image in the newer drone set).

The manifest `../photo-references.json` records original filenames, dimensions,
labels and starting viewpoints. See `../../docs/photo-matching.md` for the
in-scene photo picker and alignment export workflow. Different trips show
different vegetation conditions; the green-season photos guide scene colors.

The 13 additional drone photos are 2048 × 1152 and have no embedded EXIF camera
or GPS metadata. Their camera alignments must be set manually. The photo-matching
guide indexes the visible landmarks to help choose an alignment reference.
