# People

Quaternius "Ultimate Modular Characters" (CC0), prepared for jconra.com's Terrain Lab (one skinned mesh per
character, part classes in the vertex colours, meshopt-compressed; see ~/pw/people-pipeline). Copied from
jconra-site/models/people. `anims_f` / `anims_m` hold the clips for the women's and men's skeletons.
